    The functional agent stack

    The suite's shared seven-layer table, from /functional-copilot. This map fills in layers 3 and 4 for one function, and the identity and gate parts of layer 7; the spec builds on it.

    #LayerWhat it holdsCopilotKit piecePer function
    1Products and interfacesWhere people meet the agent: the function's own workspace, the cards and gates in it, and Slack or Teams for people who decide thereReact v2 hooks in the workspace: useComponent, useHumanInTheLoop, useAgent; CopilotChat or CopilotSidebar only where it fits; @copilotkit/a2ui-renderer, @copilotkit/mcp-apps-renderer; the Channels SDK (@copilotkit/channels-*)Built once
    2Domain capabilitiesThe jobs of one function (review, draft, check, compute, route) as tools over tested codeuseFrontendTool in the browser; defineTool in the CopilotKit Runtime on the serverSwapped
    3Context and knowledgePolicies, playbooks, history, live context, and the rules it learnsuseAgentContext; CopilotKit Intelligence: threads, memory, Automatic Learning (learning spaces, skills a person publishes, learnedSkills)Swapped
    4Data and integrationsSystems of record, through APIs and MCP serversBuiltInAgent's mcpServers; server-side tools in the runtime; fixtures behind frontend tools for v1Built once
    5Agent harnessThe loop that plans, calls tools and pauses for approval, over AG-UICopilotKit Runtime (CopilotRuntime, createCopilotRuntimeHandler) with BuiltInAgent; LangGraph, Mastra, Google ADK or Pydantic AI agents through their AG-UI integrationsBuilt once
    6ModelsAny model you choose; the key stays on the serverBuiltInAgent's model (a provider/model id) and maxSteps; a scripted LanguageModelV3 mock for demos and testsBuilt once
    7Security and governance, around every layerWho may do what, what is recorded, what can never happenGates in tool code with tests; identifyUser on the runtime; Intelligence analytics and the decision log; OpenBot for a governed coworkerBuilt once

    Developer tool for every layer: the CopilotKit web inspector (@copilotkit/web-inspector, the provider's enableInspector). Trajectories (@copilotkit/learning) are off on hosted Intelligence today.
